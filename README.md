## Build from source

Clone the branch for your Minecraft version. Use JDK 25 and pass the path to the Faktocraft 1.0.1 JAR to Gradle:

```sh
gradle build -PfaktocraftJar=/path/to/faktocraft-26.3-1.0.1.jar
```

Faktocraft is optional when running the mod.
